0. 最开始的想法是"只校不对"，就是本索引只是为大众浏览三藏提供方便而已。
0. 所以定下一个"完全一样"的原则。就是一模一样，绝没有个人丝毫意见。
0. 实际情况困难重重。主要的问题是，原影印版自身错漏，或相互不一致。
0. 所以改为"完全一致"，就是根据总目录情况，册目录情况，校勘表的情况，综合起来的一个结果。
0. 但是还是继续坚持"一模一样"，如果做不到，就降级为"完全一致"。
0. 所谓"完全一致"，需要摆事实讲道理，有影印版自身的根据。不再从其它地方找根据
0. 所有所谓"完全一致"的地方，全部标出来，留待后来者继续校验参考。
0. 优先级：册目录、正文、总目录、校勘表

0. 首先是目录，而暂不考虑内容。

0. 对了校对说明的原则，就是如果和册索引不一致，全部进行说明。
0. 至于要不要修改，也是个问题。一个原则是能不改就不改。
0. 如果要改，就是索引的页码错了，直接违反初衷，还是不好的。就是如果页码错了，还是要改的。其它能不改就不改。哈哈！
