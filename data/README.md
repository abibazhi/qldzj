# data/ 目录结构说明

乾隆大藏经数据统一为**唯一真源 + 派生切片**：

```
data/
├── sutra_table.js       唯一真源（手维护）：经表 + 卷表合并
└── cache/               派生切片（构建生成，浏览器运行时 fetch）
    ├── sutras.json      经表（目录页 idx.html）
    ├── category_map.json 分类映射（目录页）
    └── page_counts.json  册页数（翻页）
```

## 唯一真源 data/sutra_table.js

**浏览器端不直接加载本文件**，仅构建期使用；浏览器通过 `data/cache/` 切片按需加载。

记录结构（每条为一个数组，数字经号固定位置）：

```
[经号, start, end, title, translator, alias, tradTitle, rolls, gs?]
```

| 索引 | 字段 | 说明 |
|---|---|---|
| 0 | `sutra` | 经号（非数字如 `""` 为特殊记录，如勘误表） |
| 1 | `start` | 起始页码 `"册-页"` |
| 2 | `end` | 结束页码 `"册-页"` |
| 3 | `title` | 经名（含卷数，简体为主） |
| 4 | `translator` | 译者 |
| 5 | `alias` | 别名（亦名/一名，无则 `''`） |
| 6 | `tradTitle` | 繁体经名（无则 `''`）。按原版卷索引页标题誊录，**有意不含卷数**；与 `title` 的差异系字段设计而非缺失 |
| 7 | `rolls` | 卷列表 `[{t,i,b?}]` |
| 8 | `gs` | 多表分组标记（仅经1165，可选） |

卷对象字段：`t`=卷名（单卷经=千字文函号）、`i`=起始页序号（6位）、
`b`=加黑子串（排版信息；全库仅经1165 四条「xx菩萨造/释」，见下文 1165 附录）。

> **导航统一（2026-08-18）**：不再区分多卷/单卷导航形态。全部经（含单卷）都生成
> `sutra{N}.idx.html` 卷索引页；目录页每行提供**两个入口**——标题链接进阅读页、`☰` 链接进卷索引页。

## 派生切片 data/cache/

由 `back/tools/gen_cache.mjs` 从真源生成（构建产物，随 git 提交，部署无需构建）。

| 文件 | 内容 | 消费者 |
|---|---|---|
| `sutras.json` | 经表（真源前 7 字段，不含 rolls） | `idx.html`（目录页） |
| `category_map.json` | 分类映射 | `idx.html` |
| `page_counts.json` | 168 册每册页数 | `js/pageNav.js`（翻页跨册） |

> **阅读页经名/卷名不走切片**：`public/sutra{N}.idx.html` 内嵌
> `<script type="application/json" id="sutra-meta">{n,s,e,t,r:[{t,i,b?}],gs?}</script>`
> 富化数据块（gen_sutra_idx.mjs 生成，人看机器读共用一个文件）。`js/sutraInfo.js`
> 按经 fetch 当前经的 idx 页并解析该块，会话内缓存；单经数据量约 0.3–6KB(gzip)。

## 构建命令

```bash
node back/tools/gen_cache.mjs        # 重新生成 data/cache/ 切片
node back/tools/gen_index.mjs        # 生成首页 index.html
node back/tools/gen_sutra_idx.mjs    # 生成 public/sutra{N}.idx.html（全部 1670 部经，含单卷）
```

## sutra{N}.idx.html 排版规则（7 条）

由 `back/tools/gen_sutra_idx.mjs` 从真源生成。**页面为壳页**：静态部分仅
`#sutra-meta` 富化数据块（经1 另有会界样式与 `#hui-data`），表格主体、标题与
h1 由 `js/sutraIdxBoot.js` 调用共享渲染器 **`js/sutraIdxView.js`** 在浏览器端
生成——排版规则全库只有这一份实现，Node 生成器与浏览器共用（迁移时以
1670 文件零 diff 验证等价）。无 JS 时页面不显示（已接受的取舍）。

1. **字数阈值**：卷题超过 `js/config.js` 的 `ROLL_FULL_ROW_CHAR_LIMIT`（默认 24，UTF-16 码元计）→ 整行 `colspan="2"`；否则左右半列（`left-col` / `right-col`）。
2. **奇数尾**：半列条目不成对时，右列留空（`<!-- 空单元格保持布局平衡 -->`）。
3. **经0（大清三藏聖教目录）**：全部 10 条一律整行，跟随原版图片排版；页码统一阿拉伯数字，与全库一致（2026-08-22 起取消中文数字特判）。
4. **经1165（摄大乘论释）**：唯一同册内多 table 的经，四译分表（连/友/交/枝），由 `gs:[10,10,11,19]` 显式分组（共 50 卷）。
5. **加黑 `<b>`**：卷条目含 `b` 字段时，按 `indexOf` 定位子串包 `<b></b>`。全库仅经1165 有 4 处（各译卷一的「xx菩萨造/释」）。
6. **页码推导**：6 位 idx 取后 3 位、7 位 idx 取后 4 位，均去前导零；全库统一阿拉伯数字。
7. **分册**：默认按 idx 前 3 位（册号）分 table，每册一个 `<h2><a class="vol-link" href="../vols.idx.html?vol=N">第N册</a></h2>`（深链至168册目录并自动打开该册C1）；经1165 按 `gs` 分组。

### 经1 页内会界注释层（定制数据，非原版内容）

大般若经十六会的分界信息属**个人注释**而非原版内容，存放于 `sutra1.idx.html`
页尾的定制块中（由生成器 `HUI_MARKS` 常量注入）：15 组 `[idx, 会次]`
（第二会～第十六会；初会自卷一起无标记）。右上角「会界: 关/开」按钮切换，
开启时 15 个会首卷加底色并显示徽标；`localStorage('sutra1Hui')` 记忆。
此类个性化注释数据如再增多，再考虑统一归置。

### 变更流程

1. 改真源 `data/sutra_table.js`（卷条目/标记）→ 跑 `gen_sutra_idx.mjs --dry` 审查 → 落盘。
2. 调排版阈值或特殊标记（`gs`）→ 直接改真源。
3. 改经表 → 跑 `gen_cache.mjs` + `gen_index.mjs` + `gen_sutra_idx.mjs`。
4. 提交前核对：`gen_sutra_idx.mjs --dry` 零 diff、`gen_index.mjs --dry` 零 diff。
