# 特例总录（SPECIAL CASES）

> 本文件是全项目「异常点」的**唯一总账**。
>
> 数字化索引的主体（经表、卷表、勘误表）像一条平滑曲线，由真源
> `data/sutra_table.js` + 生成器固化，不需要逐条记忆；而描述这条曲线特征的，
> 是那些**异常点**——边界条件、特殊索引、特殊的字、特殊的处理。本文件把它们
> 从 README 叙事、commit message 与个人记忆中集中收拢，分类立账、逐条说明。
>
> 原则沿用 README：**不一致必须说明**。每条特例就是一个"不得不一致"的说明。

# A. 结构边界哨兵

序列两端的哨兵值，不设计内部 id，全部沿用影印版"册-页"体系。

### A1 第 0 部经《大清三藏聖教目录》 🔒
- 现象：start=`1-0`、end=`1-162`；卷索引 10 条全部整行；目录页不显示经号；封面图 `0.png`。
- 根因：整部藏经自带的御制序与原始总目录，是古代内容的**前导**，置于正式序列（1~1669）之前；经号 0 仅作"序列之前"标记。阅读范围从第 0 页起，正文页号不整体右移。
- 决策/依据：保持原样；一模一样。
- 断言：记录字段与 rolls 数量（10）。

### A2 第 169 册《勘误表》 🔒
- 现象：真源中唯一非数字经号记录（`sutra === ""`），start=`169-1`、end=`169-62`（62 页），无 rolls，目录页无经号，不生成卷索引页。
- 根因：本次数字化编排（约 2007 年）的勘误记录是**现代内容**，非古代藏经正文，故无经号；作为 168 册之外的补充，册号顺延为 169。
- 决策/依据：保持原样。与 A1 的区分——经0 是古代内容（有经号 0），169 册是现代内容（无经号）。
- 外证（2026-08-23 补充）：丽江图书馆2019、上海师大天华学院2015 所记现代影印本均为 **169册**（河北佛协2004年据台湾佛陀教育基金会版影印），「169＝168正文＋勘误」系现代影印通行形态，与本册号结构互证；详见 `docs/参考资料-出版背景.md` 九、十。
- 断言：该记录字段值。

### A3 相邻经共享边界页 🔒
- 现象：同册内相邻经存在 51 处「前经 end == 后经 start」。
- 根因：多经同卷共享物理页面（封面/卷尾）的正常形态，不是数据错误。
- 决策/依据：保持原样；连续性校验按共享边界放行。
- 断言：交叠仅允许"共享边界"与 B11 所列两条。

### B1 单卷经 roll.i 指向规则总览 ✅
- 现象：单卷非单页经 964 部的卷条目指向分三种：
  - `start+1` 共 **411** 部（有独立扉页：组首部 / 独号经 / 早期组非首部 / 扉页例外）；
  - `start` 共 **552** 部（无独立扉页，卷首即正文）；
  - `start+2` 共 **1** 部（经879，见 B6）。
- 根因：扉页占一页。有扉页则卷一在 start+1；无扉页则卷首即 start。
- 决策/依据：完全一致（按原版实际形态逐部核定）。

- 断言：三类计数与成员归属分解（B2~B5）。

### B2 多经同卷回退清单（556 部） ✅
- 现象：38 册起多经同卷仅首部经有扉页，非首部经卷条目由 start+1 回退为 start。清单：`data/multi_same_volume.md` 主表（556 条）。

- 决策/依据：完全一致；优先级 = 册目录 > 正文（封面/首页）。

### B5 回退清单内的三个特殊成因：1225 / 1239 / 1591 ✅
- 现象：三部单卷经 roll.i==start 且在回退主表生效集内，但**不属于**「组非首部」这一常规机制：
  - **1225**《略明般若末后一颂赞述》（虧二）：前 1224=卷上（虧一）、后 1226=卷上（虧三）——相邻千字文号各辖一部经连续施工；分组按"同号≥2 部才成组"，各自成孤号，multi_vol.json 中非组员；
  - **1239**《辩中边论颂》（靜十）：同理（前 1238=靜八、后 1240=情一），孤号非组员；
  - **1591**《定慧相资歌》（郡五）：郡五组**首部经**（组员 1592），但前一部 1590 是「序（郡一）」单独成号占了扉页位，1591 直接从正文开始。
- 根因：千字文分组机制（multi_vol.json）以"同函号≥2 部"为准，覆盖不到上述形态；但物理形态与回退情形相同（无扉页），故当时一并列入了回退清单——结果正确，机制上属例外成因。
- 决策/依据：完全一致。数据已正确；立条目的是防止将来按机制"纠正"它们或误判回归。
- 断言：生效集中非(组非首部)者恰为此三经，且均 i==start。

# H. 政策性约定（跨特例的通用裁决原则）

### H1 优先级链
册目录 > 正文（封面/首页）> 总目录 > 校勘表；只以影印版自身为依据。

### H2 经前序的收录政策 ⏳收集制
- 已收录：084 华严八十卷经前两序、1586 禅林宝训经前序（按正文样式）。
- 存疑：皇帝序加否（乾隆序因意识形态未入索引）；若加皇序则沙门序列是否跟进、大般若序是否跟进（现以花标分会、非为序）。
- 原则：索引已有的完全照录（不管有无名字）；自己加的以正文样式为准。⏳继续收集更多情况再定统一政策。

### H3 一经多译的作者写法
- 正文：以第 11 部经为准——经题不带作者，第一卷后跟作者；同类全部照此办理。
- 总目录：列出全部译者。

### H4 "未修改"措辞规范
备注中一律用"未修改"（客观），不用"未处理"。共享页面注释语已删（读者不关心、备注空间小）。

### H5 数字化索引的自我校验定位
- index.html 等生成物的校验属**工程校对**：错了直接改（区别于内容校对需说明）。
- 校验规则 6 条（title 一致、不带卷数、册数一致、start/end 首尾相续、page 与 start 尾数一致、卷索引可达末页）见 README §index.html 的校验；现行自动化由 gen_*.mjs --dry 零 diff 门禁承担。
