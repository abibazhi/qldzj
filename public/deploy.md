# 手机端的缩放参数
```
  let scaleFactor = 1.005; // 进一步减小缩放因子，降低缩放速度
  let zoomSensitivity = 0.05; // 进一步降低缩放灵敏度

如果后续在其他设备上测试时需要进一步微调，只需继续调整这两个值即可：

scaleFactor 越接近 1（如 1.003），缩放速度越慢
zoomSensitivity 越小（如 0.03），双指缩放的敏感度越低

```
